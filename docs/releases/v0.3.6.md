# ClineGate v0.3.6

## Model-cap reset times

- See each capped model's reset date, time, and countdown in your local timezone.
- Accounts and Models show reset times in the web dashboard and Windows desktop app.
- Upstream error messages remain available in tooltips and per-account details.
- The Tkinter source client includes a scrollable cap-detail panel with full model IDs, error codes, messages, and remaining seconds.

Reset times are estimates calculated from the provider's wait message. Timezone conversion happens on the viewing machine, including automatic Tehran time support.

## Usability fixes

- Fixed Accounts filtering, including preservation of the query and keyboard focus during refresh.
- Added a no-matching-accounts state and corrected search-field styling.
- Expanded model details remain open during refresh.
- Improved dashboard text contrast and reset-information hierarchy.
- Added horizontal scrolling and accessible model expansion space in the Tkinter client.

## Reliability

- Added regression coverage for timestamp round-tripping, timezone/date rollover, countdowns, invalid timestamps, and legacy account data.
- Isolated the device-auth route test from local account credentials and configuration.

## Windows installation

Download `ClineGateway.exe` and verify it against `checksums.sha256` if desired.
Close the running app, replace the previous executable, and keep your existing `config.yaml`, `accounts` folder, and `gateway.db`.
